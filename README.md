# 🌟 OptiSight – Intelligent Centralized Monitoring Dashboard

**OptiSight** เป็นแพลตฟอร์มที่พัฒนาขึ้นเพื่อแก้ปัญหาการกระจายตัวของข้อมูลในองค์กรขนาดใหญ่ โดยเฉพาะองค์กรที่มีระบบ IT หลายระบบ เช่น ธนาคาร บริษัท FinTech และองค์กรที่มีหลายสาขา ซึ่งทำให้ไม่สามารถมองเห็นภาพรวมของระบบทั้งหมดได้แบบ real-time 

ปัจจุบันแม้องค์กรจะมีทีม IT Operations ที่มีความเชี่ยวชาญ แต่ยังคงประสบปัญหาในการรวบรวมข้อมูลจากหลายระบบ ส่งผลให้การวิเคราะห์และตัดสินใจล่าช้า และเพิ่มความเสี่ยงด้านความปลอดภัยของข้อมูล

**OptiSight** จึงถูกพัฒนาขึ้นเพื่อเป็น **ศูนย์กลางการมองเห็นข้อมูล (Centralized Visibility)** ที่ช่วยรวมข้อมูลจากทุกระบบไว้ในแพลตฟอร์มเดียว พร้อม **ระบบแจ้งเตือนอัจฉริยะ (Smart Alerts)** และ **การตรวจจับความผิดปกติ (Anomaly Detection)** เพื่อช่วยให้ทีม IT สามารถทำงานได้รวดเร็ว แม่นยำ และมีประสิทธิภาพมากขึ้น

*หมายเหตุ: โครงการนี้อยู่ในขั้น Prototype และมีเป้าหมายในการเริ่มทดลองใช้งาน (Pilot Project) กับองค์กรจริง เพื่อพิสูจน์ประสิทธิภาพของระบบ และต่อยอดสู่การใช้งานเชิงพาณิชย์ในอนาคต*

## 🎯 กลุ่มเป้าหมายหลัก
ออกแบบมาเพื่อองค์กรขนาดใหญ่ (Large Enterprises) โฟกัสไปที่ 3 แผนกสำคัญ:
1. **IT Operations (ลูกค้าหลัก):** ใช้สำหรับดูระบบทั้งหมด เนื่องจากเป็นกลุ่มย่อยที่ต้องใช้ Monitoring tool อยู่แล้ว
2. **Security (SOC):** ใช้ตรวจจับเหตุการณ์ Hacking และแจ้งเตือนความเสี่ยงต่างๆ (Risk) ผ่านฟีเจอร์ Security 
3. **Data / Infrastructure Team:** ใช้ดูสถานะ Server, Network traffic และ Data flow ทั่วทั้งองค์กร

## 💻 ผลิตภัณฑ์และบริการ (Product & Services)

OptiSight เป็นแพลตฟอร์มประเภท Software-as-a-Service (SaaS) ที่ทำหน้าที่เป็นศูนย์กลางในการรวบรวม วิเคราะห์ และแสดงผลข้อมูลจากระบบ IT ต่างๆ ภายในองค์กร

ระบบประกอบด้วยฟังก์ชันหลัก ได้แก่
- **🎯 Dashboard:** สำหรับแสดงภาพรวมของระบบทั้งหมดแบบ real-time (ผสมผสานข้อมูล Network Traffic และ Financial Revenue Impact)
- **🚨 ระบบแจ้งเตือน (Alerts):** เตือนเมื่อเกิดความผิดปกติด้วย Smart Alerts
- **🛡️ ระบบความปลอดภัย (Security - SOC):** หน้าจอมอนิเตอร์การโจมตีและการเข้าถึงระบบ (Hacking/Risk)
- **📜 ระบบบันทึกข้อมูลย้อนหลัง (System Logs):** บันทึกร่องรอยตรวจสอบ (Audit) สำหรับ Data/Infra
- **📄 ระบบสร้างรายงาน (Export Reports):** สรุปผลการปฏิบัติงานของศูนย์ช่วยเหลือ
- **🔐 ระบบกำหนดสิทธิ์การเข้าถึง (Role-based Access Control):** ควบคุมความปลอดภัยในการเข้าหน้าเพจ

> OptiSight ไม่ได้ถูกออกแบบมาเพื่อแทนที่ทีม IT Operations แต่ทำหน้าที่เป็น **“เครื่องมือสนับสนุน (Support Tool)”** ที่ช่วยลดภาระงาน เพิ่มความเร็วในการวิเคราะห์ และช่วยให้การตัดสินใจมีความแม่นยำมากขึ้น
