# 🌟 คู่มือ Optisight Prototype ฉบับเข้าใจง่าย

เอกสารนี้จะอธิบายหน้าที่ของแต่ละหน้าจอ (Page) ในระบบ Optisight ด้วยภาษาที่ทุกคนสามารถเข้าใจได้ง่าย (Non-technical) เพื่อให้ผู้ใช้งานทุกระดับ ไม่ว่าจะฝ่ายบริหาร ฝ่ายธุรกิจ หรือฝ่ายไอที สามารถเห็นภาพรวมได้ตรงกันครับ

---

### 1. 📊 หน้า Dashboard (ภาพรวมระบบ)
**เปรียบเสมือน:** "หน้าปัดรถยนต์" หรือ "ศูนย์บัญชาการหลัก"
**หน้าที่หลัก:** รวบรวมข้อมูลสำคัญและกราฟทั้งหมดมาสรุปไว้ในหน้าเดียว เพื่อให้เห็นสุขภาพรวมของทั้งบริษัทเพียงแค่ปรายตามอง
- ดูว่ามีเครื่องคอมพิวเตอร์หรืออุปกรณ์กี่ตัวที่ออนไลน์อยู่
- เห็นปริมาณการใช้งานเครือข่ายที่วิ่งไปมาแบบสดๆ ทันที
- รู้ยอดรวมสถิติความผิดปกติ เพื่อให้พร้อมรับมือได้อย่างรวดเร็ว

### 2. 🚨 หน้า Alert Center (ศูนย์แจ้งเตือนปัญหาด่วน)
**เปรียบเสมือน:** "สายด่วนแจ้งเหตุด่วนเหตุร้าย"
**หน้าที่หลัก:** รวมข้อความแจ้งเตือนต่างๆ เวลาระบบตรวจพบความผิดปกติที่ต้องรีบจัดการ 
- ผู้ใช้งานสามารถกดเข้ามาดูรายละเอียดของปัญหา
- เมื่อจัดการเสร็จแล้วสามารถกด "รับทราบ/ปิดรับเรื่อง" เพื่อให้รายการนั้นหายไปจากหน้าจอได้

### 3. 🛡️ หน้า Security Details (รายละเอียดความปลอดภัย)
**เปรียบเสมือน:** "ห้องตรวจสอบกล้องวงจรปิดของ รปภ."
**หน้าที่หลัก:** ใช้เจาะลึกเฉพาะเรื่องความปลอดภัย (Security) โดยเฉพาะ
- เอาไว้ดูว่ามีคนพยายามเจาะระบบเข้ามาไหม
- เช็คว่าความเสี่ยงด้านความปลอดภัยในแต่ละจุดของบริษัท อยู่ในเกณฑ์ที่ปลอดภัยหรือเป็นอันตราย

### 4. 📜 หน้า System Logs (สมุดบันทึกเหตุการณ์ของระบบ)
**เปรียบเสมือน:** "สมุดจดบันทึกของยามกะดึก" 
**หน้าที่หลัก:** ระบบจะจดทุกๆ เหตุการณ์ที่เกิดขึ้นไว้อย่างละเอียดและเป็นระเบียบตามเวลา
- ใคร ล็อกอินเข้ามาตอนไหน? ใครไปเปลี่ยนการตั้งค่าอะไร? หรือเซิร์ฟเวอร์กระตุกช่วงกี่โมง? ทั้งหมดนี้จะถูกจดไว้
- เอาไว้ย้อนดูประวัติ (Audit) เวลาสืบหาสาเหตุของปัญหา หรือใช้เป็นหลักฐานยืนยันความถูกต้อง

### 5. 📄 หน้า Export Reports (ออกเอกสารรายงาน)
**เปรียบเสมือน:** "เครื่องพิมพ์รายงานเอกสารส่วนตัว"
**หน้าที่หลัก:** สร้างและดาวน์โหลดข้อมูลสรุปออกมาเป็นไฟล์
- ผู้ใช้งานสามารถสั่งให้ระบบสรุปผลการทำงาน หรือผลความปลอดภัยที่ผ่านมาแบบอัตโนมัติ
- เอาเอกสารนี้ไปส่งต่อ แจกจ่ายในห้องประชุม หรือนำไปพรีเซนต์ให้ผู้บริหารดูได้อย่างง่ายดาย

### 6. 💳 หน้า Subscription (แพ็กเกจการใช้งาน / เช่าระบบ)
**เปรียบเสมือน:** "หน้าต่างเลือกแพ็กเกจมือถือ"
**หน้าที่หลัก:** เพื่อให้องค์กรสามารถเลือกใช้งานความสามารถของระบบ ได้ตรงตามขนาดของบริษัทที่สุด
- เปรียบเทียบราคาและฟีเจอร์ของแต่ละระดับ (เช่น ระดับเริ่มต้น, ระดับกลาง, และระดับองค์กรขนาดใหญ่)
- ช่วยให้บริษัทจ่ายในสิ่งที่ตัวเองใช้จริงๆ และพร้อมขยายได้เสมอเมื่อบริษัทโตขึ้น

### 7. ⚙️ หน้า Settings (ตั้งค่าระบบส่วนตัว)
**เปรียบเสมือน:** "ห้องแต่งตัวและปรับเบาะก่อนขับรถ"
**หน้าที่หลัก:** ให้ผู้ใช้งานแต่ละคนปรับแต่งระบบตามใจชอบของตนเอง
- เปลี่ยนรูปโปรไฟล์ เปลี่ยนชื่อ แก้ไขข้อมูลติดต่อ
- ตั้งค่าได้ว่าระบบจะเตือนเมื่อเกิดอะไรขึ้นบ้าง เช่น อยากให้ระบบร้องเตือนเมื่อเครื่องทำงานหนักเกิน 80% หรือต้องการให้เตือนผ่านอีเมลเพิ่มเติม

### 8. 🔐 หน้า Login & Register (ลงทะเบียนและเข้าสู่ระบบ)
**เปรียบเสมือน:** "ประตูด่านหน้าพร้อมเครื่องสแกนบัตร"
**หน้าที่หลัก:** ป้องกันไม่ให้คนนอกเข้ามาดูข้อมูลที่เป็นความลับขององค์กร
- พนักงานจะต้องยืนยันตัวตนด้วยรหัสผ่านก่อนเข้าใช้งาน
- มีการแบ่งระดับผู้เข้าใช้ (เช่น บางคนเข้ามาดูฟีเจอร์ได้ทุกอย่าง บางคนอาจจะดูได้แค่รายงาน)
